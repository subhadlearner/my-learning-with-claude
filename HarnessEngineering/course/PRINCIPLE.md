# The principle

Set by Subhadeep on 4 October 2026. It governs every nugget and the whole curriculum.

> Start from first principles, and build on that until the concept becomes so obvious that the understanding is clear.

What this means in practice:

1. **Each nugget** starts from a plain fact that can be checked, builds in small steps where each follows from the one before, and states the idea only at the end.
2. **Each block** builds one sub-concept over its days, where each day rests only on earlier days.
3. **The curriculum** runs in dependency order, where each block rests only on earlier blocks.
4. An analogy carries each explanation, and a nugget stays a nugget: short, never an article.

This principle is not to be changed, weakened or traded for coverage, speed or brevity by any routine or by Claude. If a topic cannot be taught this way in the time available, it gets more days or is left for later; it is never taught by assertion. Only Subhadeep can change this file.
